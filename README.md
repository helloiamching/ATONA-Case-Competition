##堅持不懈地思索與實踐，是不完美的我們航向完美的唯一方法
自詡為探險家的我們，在這個滿懷理念及夢想的年紀，碰到以 普惠金融 作為主題的新光人壽，一同搭上名為ATCC的大船，懷抱著經世濟民的想法，試圖用自己的綿薄之力為偏遠地區的居民做出改變。在持續探險的過程中偶爾撿起一顆閃著亮光的石頭、幾片美麗的貝殼便欣喜不已，在抬頭望向浩翰無垠的海洋時更是興奮。這就是屬於我們「好險有統金」的冒險故事了。

##啟航-五個都市人，選擇以偏遠地區作為目標族群，可以說是非常大膽了
在得知新光人壽今年以普惠金融為主題後，我們毅然決然地參賽了。帶著想要走到最後的決心，我們在移工、銀髮族、女性等大量類型的目標族群中，選中了冷門但卻是台灣目前面臨的嚴重議題-城鄉差距造成的金融弱勢族群還。對於五個都市因仔，未曾接觸這個議題，憑著一股熱情與衝勁走進千人camp，將「好險有統金」的旗幟揚帆，入海。

##旅途-通霄，成為我們通宵的理由
面對陌生的議題，我們毅然決然地決定下鄉實地訪查，用面對面、最直接的方式和偏遠地區居民互動，用心理解他們的需求。在實際下通霄後，我們被民眾的熱情與開朗所吸引，卻也被當地金融資訊缺乏及詐騙情形氾濫所震驚。他們的口述經歷比起文獻資料所提供的數據更加直擊人心，也更加堅定了我們一定要為了他們將城鄉差距的議題帶進大舞台，讓更多人了解到台灣的每個角落的困難處。

##引航-新光，照進迷航人們心裡的光
在進入新光人壽三強時，我們也不免俗的碰上了撞牆期，再加上實地操作帶來的壓力，讓我們一度陷入低谷。好險，有著新光人壽堅強的業師團隊，多虧了廖晨旭資協坐鎮指點江山，讓我們看到遙遠燈塔的方向筆直前行；詠儀協理及芳純經理和我們一起將新光概念館實際推往苗栗通霄，而這之中當然也多虧了靜鈺、式婷、亭吟等新光同仁的幫助以及來自ATCC團隊Melody及曹總監的協助。多虧了有這些專業的領航員，幫助我們調整方向，重新起航。

##終點-去吧，我們把寶藏都藏在那裡了
在探尋的旅程中，一路跌跌撞撞，從千人camp到新光大廈，從200隊海選到晉級全國總決賽。無數個通宵的夜晚，無數次激烈討論的時光，讓我們從泛泛之交到只需一眼便心領神會的最佳戰友。我們並沒有什麼特別的方法，只是對於一件事情很長時間的、全力以赴地去考慮罷了。是偏遠地區居民們熱情的言語、包容的眼神，帶給我們動力往真理的海洋持續探索。是業師們的不斷引導及付出大量時間精力陪伴，讓我們找到正確的路程並持續前行。

好險有統金在ATCC的旅程按下了暫停鍵，在這段旅程中的歡笑，痛苦，煎熬及努力，化作一顆顆閃亮的貝殼，成為我們最珍貴的回憶。帶著這些寶藏屬於我們五人的探險故事仍會持續下去。
